# CRAG on Mobile Devices

:::{important}
This part of the User Guide is still in development.
:::

It is possible to capture data using an Android or Apple mobile phone or tablet using the Mergin Maps mobile app.
When opening a CRAG project in the Mergin Maps mobile app, you will see the same forms that are available inside QGIS.
The form configuration is controlled by the styling of each QGIS layer.
